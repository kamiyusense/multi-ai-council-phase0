## Fixed interpretation

- `KEEP_NOT_WIRED` = current safe default / no provenance advancement.
- `GITHUB_ACTIONS_READBACK_ONLY` = transport evidence only / insufficient as an independent authenticator.
- `GITHUB_OIDC_AUTHENTICATOR` = candidate / NOT_AUTHORIZED.
- `GITHUB_ARTIFACT_ATTESTATION` = strong candidate / NOT_AUTHORIZED.

A successful GitHub Actions conclusion, a JSON field, a Jules session response, or a receipt generated by the same controller does **not** authenticate itself.

For artifact attestations to provide meaningful security benefit, the attestation signature/timestamps and signer identity must be verified. Merely retrieving an attestation record is not enough.
