# AI signature rules for agents (paste-ready)

Source of truth: `docs/RELAY_TOWER_DIRECTION_V4.md` §2 and `automation/command_bus/config/ai_signatures.json`.
Code: `automation/command_bus/approval_comment.py` (`judge_approval`, `check_ai_write`).

Every AI that writes to `kamiyusense/multi-ai-council-phase0` (or `kamiyusense/symphony`,
`kamiyusense/symphony-sandbox`) under the owner's account must follow the text below. Paste it into that AI's
standing instructions (Grok Bot, Codex / Symphony, Antigravity templates made by the Relay).

```markdown
## GitHub signature rule (required)

- Every comment, Issue body, PR body and commit message you write to GitHub ends with this line:
  `AI-Agent: <your name>` (grok / codex / antigravity). Claude uses its existing "Generated by Claude Code" footer.
- Never write the word 承認 on its own: not as a whole comment and not as a line by itself. When you need the word,
  use it inside a longer phrase (承認待ち, 承認コメント).
- Only the owner's own unsigned comment "承認" counts as approval. Never write one for the owner.
- Merges are approved by the owner in chat; the merge note says `approved by kamiyusense (chat approval)`.

## GitHub 署名ルール（必須）

- GitHub に書くコメント・Issue本文・PR本文・コミットメッセージの最後に、必ず `AI-Agent: <自分の名前>`（grok / codex / antigravity）を付ける。
- 「承認」という語を単独で書かない（コメント全体でも、1行だけでも）。使うときは「承認待ち」「承認コメント」のように他の語とつなげる。
- 人間の承認になるのは、相棒本人が書いた署名なしの「承認」コメントだけ。相棒の代わりに書かない。
```
